# Spec 02: Blog Engine with Categories & Comments

## Overview
Build a modular blogging system using Python and Django.

## Requirements
- User roles: Authors and Readers.
- Post management: Title, Slug, Content, Category, Tags, Status (Draft, Published), Published Date.
- Category listing and tag filtering.
- Commenting system allowing authenticated readers to leave comments on published posts.
- Search capability across post titles and body text.
