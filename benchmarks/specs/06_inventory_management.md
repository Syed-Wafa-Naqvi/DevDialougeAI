# Spec 06: Inventory Management System

## Overview
Build an enterprise inventory control system with role-based access control in Python.

## Requirements
- Roles: Admin, Warehouse Manager, Staff.
- Product tracking: SKU, Name, Quantity, Reorder Threshold, Supplier details.
- Low-stock warning flags when item quantity drops below threshold.
- Stock movement logs (Inward stock additions, Outward dispatch records).
