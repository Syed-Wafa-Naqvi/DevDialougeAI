# Spec 01: To-Do App with User Authentication

## Overview
Build a full-featured To-Do management web application using Python and Django.

## Requirements
- User Registration & Authentication (login, logout, signup).
- Task CRUD operations (Create, Read, Update, Delete).
- Task properties: Title, Description, Priority (High, Medium, Low), Due Date, and Status (Pending, Completed).
- Filtering tasks by priority and completion status.
- Dashboard with total task counts and completion progress.
